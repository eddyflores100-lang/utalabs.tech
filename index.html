What it is

Spending that stops when trust stops.

Agent frameworks were built to act. Payment rails were built to trust. UTA is the layer between them that refuses to guess — and proves every refusal.

fail-closed by default

If the spending authority is unreachable, expired, or out of budget, the operation is denied — never silently allowed. Downtime degrades to "no", not to "yes".

Receipts, not vibes

Every decision returns a signed receipt: allow, deny, or not evaluated — each with a machine-readable reason and the identity of the authority that failed to answer. Auditors see why, not just what.

Rust · MCP · x402

A Rust core with MCP-native integration and x402-compatible metering, designed to bolt onto existing agent stacks without rewriting them — and without phoning home.
