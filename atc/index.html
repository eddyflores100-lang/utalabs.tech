Archivo 02 — un pasaporte que tu agente sí puede mostrar

Identidad que muere en voz alta cuando debe hacerlo.

Una Agent Trust Card es una tarjeta de capacidades firmada con Ed25519: quién es el agente, qué puede tocar, quién responde por él, hasta cuándo. Lo difícil no es emitir tarjetas — cualquiera emite badges. Lo difícil es des-emitirlas: ATC trae un registro público de revocación firmado (MNR-CRL-1.0) anclado a un log de transparencia append-only. Cuando una tarjeta muere, todo verificador del planeta se entera.

RULE. 02

Por qué un protocolo, no una plataforma

portable

Una tarjeta en tu repo, tu CI, tu paquete npm — no una sesión en el dashboard de otro. Los verificadores no nos llaman para confiar en una tarjeta; chequean una firma y una lista de revocación. Si AliceLabs desapareciera mañana, cada tarjeta existente seguiría verificando (o fallando correctamente) para siempre.

fingerprinted

Las tarjetas se vinculan a fingerprints criptográficos de tools (RFC 8785 JCS + SHA-256 sobre las definiciones exactas): server_hash, tools_hash, schema_hash, dependency_hash. Si la tool cambia post-auditoría → el hash cambia → la tarjeta se auto-revoca. Los upgrades silenciosos se vuelven eventos ruidosos.

transparent

Las revocaciones y digests se anclan al log público de transparencia de Sigstore Rekor — la misma infraestructura que guarda la firma de software. Tres entradas del log ya anclan nuestra primera rotación de CA. Es Certificate Transparency, reconstruido para agentes.
