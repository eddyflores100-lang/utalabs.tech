File 02 — a passport your agent can actually show

Identity that dies loudly when it must.

An Agent Trust Card is an Ed25519-signed capability card: who the agent is, what it may touch, who vouches for it, until when. The hard part isn't issuing cards — anyone can issue badges. The hard part is un-issuing them: ATC ships a public, signed revocation registry (MNR-CRL-1.0) anchored to an append-only transparency log. When a card dies, every verifier on earth knows.

RULE. 02

Why a protocol, not a platform

portable

A card in your repo, your CI, your npm package — not a session in someone's dashboard. Verifiers don't call us to trust a card; they check a signature and a revocation list. If AliceLabs disappeared tomorrow, every existing card would still verify (or correctly fail) forever.

fingerprinted

Cards bind to cryptographic tool fingerprints (RFC 8785 JCS + SHA-256 over the exact tool definitions): server_hash, tools_hash, schema_hash, dependency_hash. If the tool changes post-audit → the hash changes → the card auto-revokes. Silent upgrades become loud events.

transparent

Revocations and digests anchor to Sigstore Rekor's public transparency log — the same infrastructure that guards software signing. Three log entries already anchor our first CA rotation. It's Certificate Transparency, rebuilt for agents.
