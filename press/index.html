Press release

press release · ENfor immediate release
FOR IMMEDIATE RELEASE

AliceLabs ships utalabs.tech — a four-file trust stack for AI agents: identity, translation, audit, enforcement.

Cheyenne, Wyoming — October 2026. AliceLabs LLC today announced the public launch of utalabs.tech, the home of its AI-agent trust products. The site organizes the whole stack as a file cabinet: four files, one question — should this agent be allowed to do that?

FILE 01 — UTA, the universal trust adapter: lossless translation of agent credentials through the Universal Trust Schema, with a 12-stage verification pipeline.
FILE 02 — ATC, agent identity: a signed card format (ATC/1.0) that says who the agent is, what it may touch, and who vouches for it.
FILE 03 — Sentinel, the audit engine: what the agent's tools actually did — not what they claimed.
FILE 04 — Interceptor, policy enforcement: the decision happens before the action, not after the damage.

Every signature is Ed25519 (RFC 8032) over RFC 8785 canonical JSON. Verification is stranger-verifiable in about 30 seconds with no account, and the verification API is billed through x402 at $0.01 per call. The stack fails closed by default.

Two live deployments anchor the launch: uta-shield (wall.utalabs.tech), a provider-side MCP firewall running the stack as gates, and SLOTH (sloth.utalabs.tech), an overnight chore agent with a 1B open-weight brain (Gemma 3 + llama.cpp on a CPU) that does the boring stuff while you sleep and hands you a cryptographically signed receipt at breakfast — every action hash-chained with SHA-256 and Ed25519-signed, offline-verifiable. Irreversible clicks stay human.

"No hype colors, no vibes: every claim links to a repo, a receipt or a spec," say the AliceLabs team. "If a stranger can't verify it in 30 seconds, we don't ship it."

utalabs.tech is live now. Press contact: contacto@alicelabs.site
